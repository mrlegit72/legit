# Voice samples

Drop your own published or polished writing here as `.md` files. These are the
single most important input to the agent. Garbage in → generic AI voice out.

## What to add

- Long-form posts you've written that you're proud of (articles, threads, blog
  posts). Paste the actual text, not a paraphrase.
- 1–3 samples is enough to start. More is better.
- Suggested naming: `01-title-slug.md`, `02-title-slug.md`, etc.

## What NOT to add

- AI-generated text (even if you edited it lightly) — defeats the purpose
- Other people's writing — the agent will imitate whoever you put here
- Very short pieces (under 200 words) — too little signal

## Format

Plain markdown. The agent reads every file in this folder as voice corpus, so
keep this folder clean — only writing you actively want imitated.

If you want to mark a sample as "the canonical anchor" (the one that captures
your voice best), name it `00-canonical-*.md` and the agent will weight it
higher.
