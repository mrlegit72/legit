# Topic queue

Running list of topic ideas. The agent reads this each morning and proposes
3 angles drawn from this list (and from gaps it notices in `published/`).

**Format:** one idea per line, plain English. The shorter, the sharper.

**Workflow:**
- Add ideas any time you have one. Don't filter — capture first.
- The agent picks from this list each morning. It will NOT delete entries.
- After a topic is covered in `published/`, you may strike through with
  `~~text~~` or just leave it (the agent checks `published/` to avoid repeats).
